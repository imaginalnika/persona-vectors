02 · Mechanism

Response-token mean difference beats prompt-last

  1. Describe the trait in natural language. The pipeline builds opposing system prompts and eval questions.
  2. Collect residual-stream activations while the model answers. Average over response tokens (stronger than last prompt token).
  3. Subtract means: v_ℓ = mean(trait) − mean(anti-trait) at each layer ℓ.
  4. Pick the layer by steering effectiveness (Appendix B.4). Paper picks: Qwen L20 (evil/sycophancy), L16 (hallucination); Llama L16 for all three.
Prior Josh work in /workspace scouted base models only. Persona-vector work here targets instruct / character checkpoints — complementary, not a duplicate.

03 · Control

Post-hoc subtract cleans traits; training-time add prevents them

Monitor

Projection lights up early

Dot product of activations with v rises before trait-laden answers. Useful mid-conversation and across training.

Inference

Steer ± coef · v

Add for more trait, subtract for less. Repo modes: response / prompt / all. Strong post-hoc subtract can cost MMLU.

Training

Preventative “vaccine”

During finetune, add the bad-trait vector so the model need not shift personality to fit dirty data. Multi-layer helps.

Also: projection difference on training samples predicts post-finetune trait expression. CAFT (zero-ablate during train) helps evil/sycophancy more than hallucination.

04 · Sibling method

Vogel’s control vectors: same family, PCA + playful traits

Theia Vogel (@voooooogel) popularized easy control vectors via repeng and the 2024 Mistral “acid trip” post. Method: contrastive pairs → relative hidden states → single-component PCA per layer → add coefficient at inference.

  • 2026-10-01: persona / concept / belief / task vectors are one family (mean-diff, PCA, SAE, …).
  • Mean difference cancels shared distractors: (distress + age) − (calm + age) ≈ distress.
  • Failure modes: huge coef → collapse; entanglement; check prompt/sampler/random-vector controls.
  • Steering can jailbreak weak safety prompts; hard to jailbreak out of a strong vector.

05 · Shortlist

Four instruct picks, including Gemma 3; Qwen3.8-27B and Bonsai both real

Qwen3.8-27B exists as Qwen/Qwen3.8-27B (~27.8B post-trained VLM, Apache-2.0) — the “3.8” is the series name, not 3.8B params. Bonsai is Prism ML’s ternary pack of that model (e.g. Ternary-Bonsai-2-27B-gguf); great for local chat, poor for first-pass activation research.
