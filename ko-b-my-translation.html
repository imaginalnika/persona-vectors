페르소나 벡터는 새 파인튜닝 없이도 인스트럭트 모델을 조향한다

악함·아첨·환각 같은 성향의 활성화 공간 방향 — Anthropic 추출법, Vogel 제어 벡터와의 관계, 먼저 시도할 ~8B–27B 인스트럭트 모델.

01 · 첫 화면

성향과 반성향 활성화를 빼고, 조향하거나 백신처럼 쓴다

Anthropic 자동 파이프라인은 성향 설명을 레이어별 평균차 벡터로 바꾼 뒤 감시·조향·파인튜닝 중 예방 조향에 쓴다. 논문 데모 모델은 7B/8B 인스트럭트 두 종. 예방 조향의 MMLU 손실은 실험상 거의 없다.

02 · 메커니즘

응답 토큰 평균차가 프롬프트 마지막 토큰보다 낫다

  1. 자연어로 성향을 기술한다. 파이프라인이 반대 시스템 프롬프트와 평가 질문을 만든다.
  2. 응답 중 residual stream을 모으고 응답 토큰을 평균한다.
  3. 각 레이어에서 v_ℓ = mean(성향) − mean(반성향).
  4. 조향 효과로 레이어를 고른다(부록 B.4). Qwen: 악함·아첨 L20, 환각 L16. Llama: 세 성향 모두 L16.
/workspace의 기존 작업은 베이스 모델 스카우팅이다. 여기는 인스트럭트/캐릭터 — 보완이지 중복이 아니다.

03 · 제어

사후 빼기는 성향을 줄이고, 학습 중 더하기는 성향 유입을 막는다

감시

투영이 일찍 켜진다

활성화와 v의 내적이 성향 답 전에 커진다.

추론

±계수 조향

더하면 성향↑, 빼면 성향↓. 레포 모드: response/prompt/all. 강한 사후 빼기는 MMLU를 깎을 수 있다.

학습

예방 “백신”

파인튜닝 중 나쁜 성향 벡터를 더한다. 더러운 데이터에 맞춰 성격이 바뀔 필요가 줄어든다. 다중 레이어가 더 강하다.

학습 샘플의 projection difference는 파인튜닝 후 성향 표현을 예측한다. CAFT는 악함/아첨에 강하고 환각에는 약하다.

04 · 형제 방법

Vogel 제어 벡터: 같은 가족, PCA와 실험적 성향

Theia Vogel(@voooooogel)은 repeng와 2024 Mistral “acid trip” 글로 제어 벡터를 쉽게 만들었다. 방법: 대조쌍 → 상대 은닉상태 → 레이어별 단일성분 PCA → 추론 시 계수 가산.

  • 2026-10-01: 페르소나/개념/믿음/과제 벡터는 한 가족(평균차, PCA, SAE 등).
  • 평균차는 공유 방해물을 상쇄한다.
  • 실패: 과대 계수→붕괴, 얽힘, 프롬프트/샘플러로도 재현 가능한 효과 — 대조군 필수.

05 · 숏리스트

인스트럭트 후보 넷(Gemma 포함). Qwen3.8-27B와 Bonsai는 둘 다 있다
