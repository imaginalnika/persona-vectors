02 · 메커니즘

응답 토큰 평균 차이가 프롬프트 마지막보다 우수

자연어로 특성을 설명합니다. 파이프라인은 반대 시스템 프롬프트와 평가 질문을 구축합니다.

모델이 답변하는 동안 잔여 스트림 활성화를 수집합니다. 응답 토큰을 평균합니다 (마지막 프롬프트 토큰보다 강력).

평균을 뺍니다: v_ℓ = mean(trait) − mean(anti-trait) 각 레이어 ℓ에서.

조정 효과에 따라 레이어를 선택합니다 (부록 B.4). 논문 선택: Qwen L20 (악의/아첨), L16 (환각); Llama L16 모든 세 가지.

이전 Josh 작업은 /workspace에서 base 모델만 탐색했습니다. 여기서 Persona-vector 작업은 instruct / character 체크포인트를 대상으로 하며, 중복이 아닌 보완적입니다.

03 · 제어

사후 빼기는 특성을 정리하고, 훈련 시 추가는 이를 방지

모니터링

프로젝션은 초기부터 빛납니다

활성화와 v의 내적은 특성 가득한 답변 전에 상승합니다. 대화 중간 및 훈련 전반에 유용합니다.

추론

Steer ± coef · v

더 많은 특성을 위해 추가, 더 적은 특성을 위해 빼기. 저장소 모드: 응답 / 프롬프트 / 전체. 강력한 사후 빼기는 MMLU 비용이 들 수 있습니다.

훈련

예방적 “백신”

미세 조정 중, 나쁜 특성 벡터를 추가하여 모델이 더러운 데이터에 맞추기 위해 성격을 바꿀 필요가 없도록 합니다. 다층이 도움이 됩니다.

추론 시

예방적 (훈련)

더러운 데이터에 대한 SFT 후

h ← h − α · v

↓ 특성, 위험 ↓ 능력

더러운 데이터에 대한 SFT 중

h ← h + α · v

특성 드리프트 제한, MMLU 유지

또한: 훈련 샘플의 프로젝션 차이는 미세 조정 후 특성 표현을 예측합니다. CAFT(훈련 중 제로-어블레이트)는 악의/아첨에 더 도움이 되며 환각에는 덜 도움이 됩니다.

04 · 형제 방법

Vogel의 제어 벡터: 같은 계열, PCA + 유희적 특성

Theia Vogel (@voooooogel)은 repeng과 2024 Mistral “acid trip” 게시물을 통해 쉬운 제어 벡터를 대중화했습니다. 방법: 대조 쌍 → 상대적 숨겨진 상태 → 단일 구성 요소 PCA 각 레이어 → 추론 시 계수 추가.

2026-10-01: 페르소나 / 개념 / 신념 / 작업 벡터는 하나의 계열입니다 (평균 차이, PCA, SAE, …).

평균 차이는 공유 방해 요소를 취소합니다: (고통 + 나이) − (평온 + 나이) ≈ 고통.

실패 모드: 큰 계수 → 붕괴; 얽힘; 프롬프트/샘플러/랜덤 벡터 제어 확인.

조정은 약한 안전 프롬프트를 탈옥할 수 있습니다; 강한 벡터에서 탈옥하기는 어렵습니다.

05 · 쇼트리스트

네 가지 instruct 선택, Gemma 3 포함; Qwen3.8-27B와 Bonsai 모두 실재

Qwen3.8-27B는 Qwen/Qwen3.8-27B로 존재합니다 (~27.8B 후 훈련 VLM, Apache-2.0) — “3.8”은 시리즈 이름이며, 3.8B 파라미터가 아닙니다. Bonsai는 해당 모델의 Prism ML의 삼진 패키지입니다 (예: Ternary-Bonsai-2-27B-gguf); 로컬 채팅에 좋고, 첫 번째 활성화 연구에는 부적합합니다.

선택 모델 크기 이유 GPU (BF16)
A Qwen/Qwen2.5-7B-Instruct ~7.6B 논문 기준; Apache-2.0; 알려진 레이어 ~16 GB (4090 / A10 / L4)
B NousResearch/Hermes-3-Llama-3.1-8B ~8.0B Instruct + 롤플레이 가능; 캐릭터 각도 ~16–20 GB

D google/gemma-3-12b-it ~12.2B 최신 Gemma 3 instruct 인밴드; 기존 페르소나 벡터 아티팩트; 제한된 Gemma 라이선스 ~24 GB BF16 (4090 / A5000); AWQ ~12–16 GB

논문은 또한 Llama-3.1-8B-Instruct를 사용했습니다. 커뮤니티 RP 대안: Humanish-Roleplay-Llama-3.1-8B.
